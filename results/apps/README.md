# 勝ちパターンの応用デモ（2026-10-23）

勝ちパターン＝「オラクル入力・問い合わせ計算量に分離のある汎関数（Forrelation）・2 次に落ちない位相・1 ビット読み出し」。
検討した 6 応用のうち、数値デモで優位が確認できたのは 2 件、デモ前の検討で優位が消えると判明したのが 2 件。

| 応用 | 判定 | 根拠 |
|---|---|---|
| A. 2 つのブラックボックス過程の Fourier 双対関係の劣化監視 | **勝ち（黒箱）／負け（白箱）** | `drift_monitoring.md` |
| B. 指数和相関（Kloosterman 和）の計算スケーリング | **勝ち（n ≳ 40 で古典が年単位）** | `exp_sum_scaling.md` |
| 光通信の符号同期（隠れシフト） | 負け | 受信側が参照符号を白箱で知るため、Q サンプルの相関で O(log N) 問い合わせで同定できる。黒箱双対（受信側が符号を知らない）でしか量子優位は出ない |
| Boolean matching（アフィン不変核） | 不成立 | 不変性群 Φ(f∘A, g∘A⁻ᵀ)=Φ(f,g) は「対を同時に変換」したときの不変性で、片側だけ変換した関数の類似度にはならない。前回の表の記述は過大だった |
| 鍵付き関数の構造監査（Q2 モデル） | 未デモ | 構造は A と同一（黒箱双対の検出）。コヒーレント問い合わせの脅威モデル仮定が別途必要 |
| 量子過程入力の時系列学習 | 未デモ | 問い合わせ下界ではなくシミュレーション困難性に依存し、本枠組み（厳密模倣）では両軸の勝ちを示せない |

## デモ A：双対関係の劣化監視（Kloosterman 参照、n=16、3 seed）

デバイス g_t の理想関係 g = sign Ĥf への忠実度 p_t ∈ [0.3, 1] が OU 過程＋ジャンプでドリフト（g_t は各成分を確率 (1−p_t)/2 で反転、E[Φ_t] = p_t·Φ_YES）。目的は p_t と Φ_t の追跡。全監視器に同一の調整済み読み出し。

| 監視器 | 問い合わせ/ステップ | NMSE |
|---|---|---|
| 量子 m=10² ショット | 200 | **0.161** |
| 量子 m=10³ | 2000 | 0.039 |
| 量子 m=10⁴ | 20000 | 0.0052 |
| 古典黒箱 naive | 200 / 2000 / 20000 | 1.00 / 1.01 / 1.01 |
| 古典黒箱 opt（√N 楽観代理） | 200 / 2000 / 20000 | 0.96 / 0.72 / 0.235 |
| 古典白箱（理想 g を知る） | 200 / 2000 / 20000 | 0.069 / 0.012 / 0.0017 |

- 黒箱：量子 200 問い合わせが古典の 20000 問い合わせ（楽観モデル）を上回る。問い合わせ比 100 倍超。
- 白箱：古典が g を知っていれば g_t(y)g(y) の標本平均で分散 (1−p²)/Q、N 非依存。同一問い合わせ数で古典が 2.3 倍良い（量子は 1 ショットに 2 問い合わせ）。**量子優位は「理想関係が古典的に計算できない（または未知の）2 過程」の監視に限られる。**

## デモ B：指数和相関のスケーリング（Kloosterman 対、目標精度 ±0.03）

| n | N | Φ | 古典厳密（2 回 FWHT）[s] | 量子問い合わせ（2m） |
|---|---|---|---|---|
| 16 | 65536 | 0.8490 | 0.001 | 622 |
| 20 | 1048576 | 0.8488 | 0.018 | 622 |
| 24 | 16777216 | 0.8488 | 0.652 | 622 |
| 40（外挿） | 10¹² | — | 110 時間 | 622 |
| 50（外挿） | 10¹⁵ | — | 58 年 | 622 |
| 60（外挿） | 10¹⁸ | — | 2.7×10⁵ 年 | 622 |

実測 log₂(時間) ≈ 1.22n − 30.2。量子は精度固定なら n に依らず 622 問い合わせ（1 ショットあたりのオラクル回路 GF(2ⁿ) 逆元は poly(n) で別勘定）。古典の問い合わせ制限推定は Ω(√N/log N)：n=40 で 10⁶、n=60 で 10⁹。Kloosterman Φ は n→大で 0.8488 に収束しており（文書 §6 の下界 1/√2 と整合）、「古典が届かない体サイズでの Φ の値」そのものが数論的な測定対象になる。

## 共通の但し書き

- 勝ちは問い合わせモデルでの話。古典側が構造（理想関数・seed・2 次性）を白箱で知ると消える（A の白箱対照、第 4 波の Gold 対）。
- 量子側のオラクル実装コストは未計上。n=16 での絶対時間は古典 FWHT が圧倒的に速い。優位は n ≳ 40 と、オラクルが物理過程として与えられる場合に限る。
